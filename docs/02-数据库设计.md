# VisionQC 数据库设计 V1

> 所有建表由 Flyway 管理，脚本位于 `backend/src/main/resources/db/migration/`。
> 状态字段一律用 `VARCHAR` 存枚举名（DB 层可读、迁移成本低），Java 层用枚举映射。

## 1. 表清单与职责

| # | 表名 | 职责 | 关键约束 |
|---|------|------|----------|
| 1 | users | 用户主数据 | username 唯一；password 存 BCrypt |
| 2 | roles | 角色字典（ADMIN/INSPECTOR/REVIEWER） | code 唯一 |
| 3 | user_roles | 用户-角色多对多 | (user_id, role_id) 联合唯一 |
| 4 | devices | 生产设备 | device_code 唯一；status 控制启停 |
| 5 | production_batches | 生产批次 | batch_code 唯一；FK device |
| 6 | image_assets | 图片资产（元数据） | sha256 + batch 联合唯一（批次内去重）；FK batch |
| 7 | defect_categories | 缺陷分类字典 | code 唯一；逻辑删除 |
| 8 | inspection_tasks | 质检任务 | FK image；FK inspector/reviewer；version 乐观锁；status 状态机 |
| 9 | annotations | 矩形标注 | FK task；级联由应用层控制 |
| 10 | review_records | 审核历史（每次通过/驳回一条） | FK task/operator |
| 11 | audit_logs | 审计日志（所有状态变更） | 独立于业务表，不存敏感信息 |

## 2. 字段设计

### 2.1 users
```sql
id            BIGINT PK AUTO
username      VARCHAR(50)  NOT NULL UNIQUE
password      VARCHAR(100) NOT NULL              -- BCrypt(60)
display_name  VARCHAR(50)  NOT NULL
enabled       TINYINT(1)   NOT NULL DEFAULT 1
created_at    DATETIME(6)  NOT NULL
updated_at    DATETIME(6)  NOT NULL
deleted       TINYINT(1)   NOT NULL DEFAULT 0    -- 逻辑删除
```

### 2.2 roles / user_roles
```sql
roles: id BIGINT PK, code VARCHAR(20) UNIQUE, name VARCHAR(50)
user_roles: user_id FK→users.id, role_id FK→roles.id, PRIMARY KEY(user_id, role_id)
```

### 2.3 devices
```sql
id            BIGINT PK AUTO
device_name   VARCHAR(100) NOT NULL
device_code   VARCHAR(50)  NOT NULL UNIQUE
device_status VARCHAR(20)  NOT NULL DEFAULT 'ENABLED'   -- ENABLED/DISABLED
description   VARCHAR(255)
created_at / updated_at  DATETIME(6) NOT NULL
deleted       TINYINT(1)  NOT NULL DEFAULT 0
```

### 2.4 production_batches
```sql
id           BIGINT PK AUTO
batch_code   VARCHAR(50)  NOT NULL UNIQUE
device_id    BIGINT       NOT NULL FK→devices
product_type VARCHAR(100) NOT NULL
capture_date DATE         NOT NULL
status       VARCHAR(20)  NOT NULL DEFAULT 'OPEN'  -- OPEN/CLOSED
created_at   DATETIME(6)  NOT NULL
deleted      TINYINT(1)   NOT NULL DEFAULT 0
INDEX idx_batch_device (device_id, capture_date)
```

### 2.5 image_assets
```sql
id           BIGINT PK AUTO
batch_id     BIGINT      NOT NULL FK→production_batches
file_key     VARCHAR(120) NOT NULL UNIQUE   -- 服务端生成：{uuid}.{ext}
sha256       CHAR(64)    NOT NULL
width        INT         NOT NULL
height       INT         NOT NULL
size_bytes   BIGINT      NOT NULL
content_type VARCHAR(50) NOT NULL
status       VARCHAR(20) NOT NULL DEFAULT 'ACTIVE'  -- ACTIVE/DELETED
created_at   DATETIME(6) NOT NULL
UNIQUE uk_batch_sha (batch_id, sha256)       -- 批次内去重
INDEX idx_img_batch (batch_id, status)
```
> 图片文件本体存 `vqc-storage/{batch_id}/{file_key}`，与元数据分离；file_key 由服务端 UUID 生成，用户文件名只存 `original_name`。

### 2.6 defect_categories
```sql
id       BIGINT PK AUTO
code     VARCHAR(50)  NOT NULL UNIQUE   -- SCRATCH/DENT/CRACK/...
name     VARCHAR(100) NOT NULL
description VARCHAR(255)
enabled  TINYINT(1)   NOT NULL DEFAULT 1
deleted  TINYINT(1)   NOT NULL DEFAULT 0
```

### 2.7 inspection_tasks
```sql
id            BIGINT PK AUTO
image_id      BIGINT      NOT NULL FK→image_assets
inspector_id  BIGINT      NULL FK→users    -- 创建任务时可为空，分配后填
reviewer_id   BIGINT      NULL FK→users
status        VARCHAR(20) NOT NULL         -- 状态机，见《03-状态机与审核流程》
version       INT         NOT NULL DEFAULT 0   -- JPA @Version 乐观锁
remark        VARCHAR(500)
created_at / updated_at DATETIME(6) NOT NULL
INDEX idx_task_status (status, image_id)
INDEX idx_task_inspector (inspector_id, status)
```

### 2.8 annotations
```sql
id          BIGINT PK AUTO
task_id     BIGINT NOT NULL FK→inspection_tasks
category_id BIGINT NOT NULL FK→defect_categories
x_norm      DECIMAL(8,6) NOT NULL   -- 归一化坐标 0~1，标注不随缩放偏移
y_norm      DECIMAL(8,6) NOT NULL
w_norm      DECIMAL(8,6) NOT NULL
h_norm      DECIMAL(8,6) NOT NULL
img_width   INT NOT NULL            -- 标注时原图尺寸，用于审计
img_height  INT NOT NULL
note        VARCHAR(255)
created_at  DATETIME(6) NOT NULL
updated_at  DATETIME(6) NOT NULL
INDEX idx_ann_task (task_id)
```

### 2.9 review_records（审核历史，只增不改）
```sql
id          BIGINT PK AUTO
task_id     BIGINT NOT NULL FK→inspection_tasks
operator_id BIGINT NOT NULL FK→users
action      VARCHAR(20) NOT NULL    -- APPROVE/REJECT/SUBMIT/ASSIGN/RESUBMIT
from_status VARCHAR(20) NOT NULL
to_status   VARCHAR(20) NOT NULL
comment     VARCHAR(500)             -- 驳回必填（应用层校验）
created_at  DATETIME(6) NOT NULL
INDEX idx_review_task (task_id, created_at)
```

### 2.10 audit_logs（系统审计，只增不改）
```sql
id          BIGINT PK AUTO
operator_id BIGINT NULL FK→users
action      VARCHAR(50) NOT NULL     -- LOGIN/CREATE_DEVICE/...
entity_type VARCHAR(50) NOT NULL
entity_id   BIGINT
detail      VARCHAR(500)             -- 变更说明（JSON 摘要）
created_at  DATETIME(6) NOT NULL
INDEX idx_audit_time (created_at)
```
> 审计表绝不记录密码、Token、Session ID。

## 3. ER 关系（文本图）

```
users 1..* --- user_roles *.. 1 roles
devices 1 --- * production_batches
production_batches 1 --- * image_assets
image_assets 1 --- 1 inspection_tasks   （一图一任务）
users(质检员) 1 --- * inspection_tasks（被分配）
users(审核员) 1 --- * inspection_tasks（审核）
inspection_tasks 1 --- * annotations * --- 1 defect_categories
inspection_tasks 1 --- * review_records * --- 1 users
users 1 --- * audit_logs
```

## 4. 关键设计决策

| 决策 | 理由 | 备选方案（及放弃原因） |
|------|------|------------------------|
| 逻辑删除用 deleted 标志 | 质检数据必须可追溯，物理删除会破坏历史引用 | 物理删除（破坏审计链） |
| 坐标用归一化 DECIMAL(8,6) | 前端缩放/换分辨率不漂移；DECIMAL 避免浮点误差 | 像素坐标（缩放即偏移） |
| 一图一任务 | 图片批次审核进度天然按图统计；避免同图多任务重复计数 | 一图多任务（统计口径复杂） |
| (batch_id, sha256) 唯一约束 | 同批次重复上传幂等返回已有记录；跨批次允许同图 | 全局 sha 唯一（不同批次合法重复上传被误杀） |
| version 乐观锁 | 无锁等待、适配 Web 场景，冲突返回 409 | 悲观锁（SELECT FOR UPDATE，阻塞体验差） |
| 状态用 VARCHAR 枚举 | SQL 可读、Flyway 迁移简单 | TINYINT（调试困难） |
