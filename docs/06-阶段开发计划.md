# VisionQC 阶段开发计划 V1

## Phase 0（本次交付）：设计 + 骨架 + 最小闭环

**输出物**
- docs/01~05 设计文档（需求架构 / 数据库 / 状态机 / API / 前端结构）
- 后端：可启动的 Spring Boot 3 骨架，Flyway V1 建表（11 表），登录认证 + 设备/批次最小 CRUD，全局异常处理，测试通过
- 前端：可构建的 Vue 3 骨架，登录页真实联调，10 个页面路由就位，axios 封装 + 401/409 拦截
- 项目落盘 `vqc`，git 初始化首次提交

**验收**
- `mvn test` 通过（无 DB 依赖的单元测试 + 状态机单测）
- `npm run build` 通过
- 后端连库启动后：登录 → 创建设备 → 创建批次 全链路可跑（需 MySQL 密码后补验）

## Phase 1：全栈基础完善

- 用户管理页 + 接口（ADMIN 创建用户/改密码/禁用）
- 设备/批次页完整 CRUD 对接、分页搜索
- audit_log 登录/登出记录
- 验收：前后端联调，三种角色各登录一遍权限正确

## Phase 2：图片与标注

- 上传（多文件、类型/大小校验、SHA-256、暂存→DB→原子 rename）
- 图片列表/预览（流式输出）
- Fabric.js 标注工作台：缩放、拖动、画/编辑/删矩形、选类别、备注、保存/恢复
- 失败路径测试：非法格式、超大文件、中断上传（验收场景 E 的前半）
- 端到端测试：场景 A

## Phase 3：审核业务

- 任务创建/分配、状态机全转换 + 非法转换拒绝
- submit/approve/reject/resume + 权限矩阵（场景 D）
- 乐观锁 409 + 集成测试双事务竞争（场景 C）
- 审核历史/审计日志页（场景 B 全流程）

## Phase 4：统计与性能

- 统计接口（统一定义的指标口径）+ ECharts 看板（场景 F：样本数据人工核算一致）
- CSV 导出（BOM + 公式注入防护）
- 查询 A/B 优化：EXPLAIN 前后对比，产出 docs/08-查询优化报告.md
- 安全检查：路径穿越、越权、敏感信息不落日志

## Phase 5：最终交付

- 单元/集成/并发测试补全与报告
- Swagger 截档、演示数据 seed（Flyway V2 data migration 或 dev profile）
- README（启动/测试/演示流程）、简历技术亮点、面试追问依据（docs/09、10）

## 里程碑检查点
