## 2. 结构

```
src/
├── api/            # axios 实例 + 按域封装（auth.js device.js batch.js image.js task.js stats.js）
├── stores/         # Pinia: auth.js（用户+角色+登录态，持久化 sessionStorage）
├── router/index.js # 路由守卫：未登录→/login；角色不匹配→403 页
├── components/
│   ├── AppLayout.vue   # 侧边菜单+顶栏（按角色渲染菜单）
│   └── PageCard.vue
├── views/          # 上表 10 页
└── main.js
```

## 3. 关键机制

- **请求封装**：`api/request.js` 创建 axios 实例，`withCredentials: true`；响应拦截器统一处理 401→跳登录、409→ElMessage 警告“记录已被其他用户修改”。
- **加载状态**：每页 `loading` ref 控制表格 `v-loading`。
- **表单校验**：Element Plus `rules`（必填/长度/编码格式）。
- **刷新恢复**：登录态存 Pinia + sessionStorage；标注工作台从后端按 taskId 拉取恢复。
- **路由权限与后端一致**：菜单隐藏只是体验，后端接口同样校验（双层保障）。
- **错误提示**：拦截器统一 ElMessage.error(message)，页面不再重复弹。
